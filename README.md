# TMT project page

Project website: https://zzr42.github.io/tmt/

## Editing and preview

Edit `index.html` for page content and `static/css/project.css` for styling.
Run `python3 -m http.server 8765 --bind 127.0.0.1` and open http://127.0.0.1:8765/.

Video sources can be added to `static/js/demo-config.js`. Paper, code, and arXiv links will be added when available.

GitHub Pages serves the `main` branch from the repository root. Push updates to `main` to publish them.
